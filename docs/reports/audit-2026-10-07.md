## 一、确证 bug（实测复现，按严重度）

### B1【中-高】loudnorm 增益无峰值保护 → 高动态素材削波　✅ 已修复（1.4.6）
- 位置：`src/sunoauxtool/dsp/ops.py:122-123`
- 实测：稀疏脉冲输入（峰值 0.5，LUFS -28.1）拉到 -16 LUFS → +12.1dB 增益 → 输出峰值 **2.0**；
  唯一防线是 `export/audio.py:49` 写盘时硬 clip → **削波失真**。
- 触发面：crest（波峰因数）>10-12 的高动态素材（古典/影视配乐/广播剧）+ 激进目标；普通素材
  （crest ≤8）实测不触发。
- 修复建议：`loudnorm` 后自动串联 `filters.limiter(ceiling=-0.3)`（已有现成实现），
  或加 `--ceiling` 参数允许关闭。

### B2【中】tempo.beat_offset 双重除以 rate → 节拍网格全错　✅ 已修复（1.4.6；1.5.1 精度增强）
- 位置：`src/sunoauxtool/analysis/tempo.py:249+254`
- 实测：第一拍在 0.25s 的点击轨返回 **0.00256s**（= 0.25 / 86.13，被 rate 除了两次）。
- 影响：`video/videomaker.py:143` 用它生成节拍网格 → `--tempo-grid` 视频节拍对齐必错；
  `cli.py:1010` 显示错误相位。
- 修复：删掉多余的一次 `/ rate`（一行），补相位回归测试（合成点击轨已知相位）。
- 1.5.1 精度增强：半窗校正 `frame/(2·sr)` 换为通量峰位公式
  `1.25·argmax(Hann²[p]−Hann²[p+hop])` + 相位得分抛物线细化——
  合成点击轨相位误差 mean 11.5ms/max 20.9ms → **mean 1.25ms/max 4.24ms**。
  详见 `plan-1.5.1-beat-phase.md`。

### B3【中】loudness K 加权系数缩放缺 bilinear 步骤 → 非 48k 增益系统性偏置　✅ 已修复（1.4.6）
- 位置：`src/sunoauxtool/dsp/loudness.py:31-44`（`_scale_stage`）
- 实测频响偏差：**44.1kHz：-2.05dB@1kHz、+1.34dB@100Hz；22.05kHz：+5.97dB@100Hz、+4.09dB@1kHz**
  （48kHz 精确）。docstring 称"pyloudnorm 同款公式"不成立——pyloudnorm 按原型 G/Q/fc
  对每个 sr 重新做 bilinear 变换，本实现跳过了该步。
- 影响：非 48k 输入的 `loudnorm` LUFS 测量偏置 → 增益错误（普通流行乐 ±1-2dB，
  低采样率素材最多 ±6dB）。
- 修复：按 pyloudnorm 方式对每个 sr 重新 bilinear（系数是 fc/sr 的函数，直接算即可）。

### B4【中】concat 声道数不匹配 → 裸 ValueError 无诊断　✅ 已修复（1.4.6）
- 位置：`src/sunoauxtool/dsp/ops.py:290-309`（`op_concat`）
- 实测：mono 拼 stereo → `np.concatenate` 抛裸 ValueError，被包装成含 numpy 原文但
  无业务诊断的 DspError。采样率不一致有前置重采样，**声道数没有**。
- 修复：前置校验声道数，不匹配时 `DspParamError(16)` 提示（或自动 upmix/downmix）。

### B5【中→文档】`errors` 命令与 README 错误码表不完整（主审自查发现）　✅ 已修复（1.4.6）
- `sunoauxtool errors` 表缺 **10-14（video）** 与 **20-24（download 取证）** 段
  （`exceptions.py:21-36` 只登记了 0-9/15/16/25/26；实际代码两段都在用）。
- README「错误码」节只列到 9——缺 15/16/20-26 全部扩展段。
- 修复：`ERROR_CODES` 补 10 段与 20 段（video/download/exceptions.py 已有语义文案可抄）；
  README 表同步。

### B6【中→预防】torch.load 19 处无 `weights_only`（主审自查发现）
- 分布：**全部在上游 VASR 克隆**（`versatile_audio_super_resolution/audiosr/`，自有代码 0 处）。
- 影响：当前 torch 2.5.1 无影响；**升级 torch ≥2.6 时全部加载点必炸**（weights_only 默认翻转）。
- 修复：`scripts/setup_vasr.py` 补丁链追加"torch.load(...) → weights_only=False"批量补丁；
  或统一 monkeypatch。登记为升级前置检查项。
